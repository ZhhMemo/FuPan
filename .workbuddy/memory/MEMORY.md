## 项目定位

**复盘**（原名「温故」，2026-09-16 用户拍板改名）——
用真实历史数据当考题、用真实行情当判卷的 A 股决策训练工具。
不是荐股软件，不是模拟炒股，是**学习平台**。
一句话：一组区间，一次判断，一个真实结果。

用户已明确：**仅个人学习自用，不考虑合规与对外发布**。不要反复提合规建议。
（形态已升级为 Web UI + 可部署 Linux 云服务器 + 认证登录，但仍不对外公开。）

## 核心机制（不可改动的前提）

1. 用户选股 → 系统切出若干候选区间 → 用户选一个区间
2. 界面**只显示决策点之前的数据**（含指标、财务、公告）
3. 用户**实际下单**（买入/卖出 + 股数），不是三选一选择题
4. 用区间之后的真实行情结算，输出**账户视角**收益 + 对标沪深300
5. **不判定成功/失败**，只给事实数据

> **2026-09-16 修订**：第 3 步原为「三选一（买入/持有/卖出）」，
> 用户要求改为**真实仓位交易**。附带解决了原设计一个硬伤——
> 无仓位时「持有」和「卖出」执行结果完全一样（都等于不建仓）。

## 三条必须守住的技术红线

1. **前视偏差**：屏蔽未来必须做在**后端**。前端不渲染等于没做。
   滚动指标必须用「截止当日」窗口，禁止全历史归一化（隐性泄题）。
2. **模型侧前视**：喂给 AI 的数据要脱敏，不含真实日期与股票名。
   否则模型可能"记得"那段行情而泄题。
3. **幸存者偏差**：数据必须含退市股，出题要用 point-in-time 时点标的池
   （"那天在市的股票"），不是"今天在市"的股票。

## 反直觉但重要的设计

- **机会成本**必须与超额收益配对输出。否则用户「一直选卖出」，
  在熊市里收益率恒为 0%，会永远"跑赢"基准，从而学到完全错误的策略。
- **不复权 ≠ 真实收益**。分红送股后股数和现金都变了，必须用后复权算收益。
- **前复权数据不能落库**，因为每次新除权都会重算全部历史。

## 知识复盘模块（技术知识学习）

定位：作答**后**弹出本区间出现过的知识点，供巩固记忆。**支持关闭/开启**。

**2026-09-16 重大修订**：原设计（作答前给知识点 + 方向配平干扰项）**已作废**。
用户拍板改为作答前完全不给知识点。副作用是**泄题风险归零、设计反而更简单**——
配平机制、防依赖的"随机裸考"全部删除，开关从三级收敛为两级。

| 阶段 | 定位 | 边界 |
|---|---|---|
| 作答前 | 什么都不给 | **界面不出现任何知识点 / 形态标注 / 信号提示** |
| 作答中 | 给工具，不给结论 | 指标（均线/MACD/KDJ/BOLL）**默认开启**；指标线**绝不允许延伸到决策点之后** |
| 作答后 | 揭晓 + 巩固 | 匹配到的**全部**知识点分层展示；同一知识点多次命中合并计数、可展开逐次位置 |

**一条仍要守住的规则**：开关状态（`knowledge_mode`）**不再做成绩分账**
（作答难度不受开关影响），改为统计"复盘查看率"这类学习行为指标。

**杀手锏功能（保留）**：用全 A 股 30 年数据统计每个形态的真实胜率
（出现次数 / 上涨概率 / 平均收益 / 跑赢沪深300 概率）。
三条纪律：用全样本、必须含退市股、必须标样本量（不足 100 次标"数据不足"）。

**实现要点**：匹配引擎统一抽象 `Detector.detect(ohlcv_slice) -> List[Occurrence]`，
分 `point`（逐根滑窗）与 `persistent`（区间状态）两路；显著性打分用可解释规则
（strictness / confirmation / position / duration / direction_clarity），
**confirmation 必须用"决策点之前"的确认度**，否则是前视偏差。
展示层默认展开前约 40%，其余收"查看全部"，**不设数量硬上限**。
